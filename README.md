# Foodi Client

This is the client-side of the **Foodi** project, built using **React** and **Vite** for a fast and efficient development experience.

## Overview

The project is deployed and accessible [here](https://foodi-client-5k1cb2rcm-nabilhatami86s-projects.vercel.app/).

This template provides a minimal setup to get **React** working with **Vite**, featuring:

- Hot Module Replacement (HMR) for a seamless development experience
- ESLint rules for code quality and consistency

## Features

- **Fast Refresh**: With Vite's HMR and React's Fast Refresh, any updates to your components are instantly reflected in the browser.
- **Linting**: ESLint integration ensures that your code follows best practices.

## Plugins Used

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md): Utilizes Babel for Fast Refresh.
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc): Utilizes SWC for Fast Refresh.

## Getting Started

To run this project locally:

1. Clone this repository.
2. Install dependencies using `npm install`.
3. Start the development server with `npm run dev`.
